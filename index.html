SKILL SHOWCASE

随口记账，认真落账

`daily-expense-ledger` 是一个面向日常生活消费的 SKILL 技能：把口语化支出转换为可追溯的本地 Markdown 账本，并支持日结、月末账单与手机便签同步。

仅记录支出 Markdown 持久化 Python 脚本驱动 UTC+8 日期 移动端适配
3类目标用户：学生、工作党、家庭主妇
8个内置消费类别，支持自定义
3个可携带 Markdown 数据文件
1.0.3当前技能版本
触发 能力 产出

内容结构：从一句话到 可复用账本

识别自然语言

用户可以说“午饭花了 18 元”“昨天坐地铁 12 元”，技能提取金额、描述、日期、类别、币种和备注。

  • 缺金额或用途时追问，不臆造
  • 历史日期允许补录，未来日期拒绝

维护支出记录

所有新增、查询、编辑和删除都通过 `scripts/ledger.py` 执行，避免手动改表导致账本损坏。

  • 记录成功返回 ID 与完整字段
  • 重复候选必须等待用户确认

生成汇总报告

日结可按指定历史日期生成；月末账单仅在自然月最后一天可用，并保存月度快照。

  • 按币种分别汇总
  • 按身份和语气定制建议

执行流程：小而稳的 记账闭环

STEP 01

初始化身份、默认币种和汇总语气。

STEP 02

把口语消费解析为标准字段。

STEP 03

脚本写入本地 Markdown 账本。

STEP 04

按日或月末生成报告。

STEP 05

用户确认后同步到手机便签。

ledger commands
python scripts/ledger.py config show
python scripts/ledger.py init --identity student --tone friendly
python scripts/ledger.py add --amount 18.5 --description "午饭" --category food
python scripts/ledger.py list --date 2026-07-21
python scripts/ledger.py daily
python scripts/ledger.py monthly
设计小心机

技能把“AI 理解自然语言”和“脚本确定性落账”分开：前者灵活，后者可验证。账本这东西，浪漫归浪漫，账不能糊。

数据结构：三份 Markdown，轻巧可携带

DATA LOCATION

默认保存到用户主目录

账本优先写入 `~/.daily-expense-ledger/`，并支持 `--data-dir` 与 `DAILY_EXPENSE_LEDGER_DATA_DIR` 指定可写目录，兼容 Android 等受限环境。

WRITE RULE

只让脚本写账本

技能明确要求所有读写通过 `ledger.py` 完成；脚本负责表格转义、重复检测、未来日期拒绝和临时文件替换写入。

文件 保存内容 展示价值
`config.md` 身份、语气、默认币种、初始化时间 让汇总报告能按用户身份与交流偏好输出
`expenses.md` 不可变 ID、日期、金额、描述、类别、币种、备注、创建/更新时间 构成账本主数据，支持查询、编辑、删除和统计
`monthly_summaries.md` 按 `YYYY-MM` 分节保存的月度账单快照 同月重复生成时替换快照，避免重复堆积

规则边界：把“会记账”变成 可靠记账

不记录收入

用户输入包含收入、工资、奖金等收入关键词时，技能直接拒绝记录，保持账本语义单一。

不抢跑确认

重复记录、删除操作、手机便签同步都需要用户明确确认，成功与否以脚本或 MCP 返回为准。

不合并币种

日结和月度账单按币种分别汇总，避免把不同币种金额揉成一个看似漂亮但不真实的数字。

不假装成功

MCP 便签工具不存在、未授权或调用失败时，只能如实说明，不能口头声称已保存。

这个技能的核心不是“多会说”，而是每次都知道自己处在等待信息、等待确认、执行中、已完成还是已失败。
